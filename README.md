# E-Commerce Data Analytics Project

## Overview
This repository contains a comprehensive E-Commerce Data Analytics project focused on sales performance and customer behavior analysis. The project follows a structured methodology to solve e-commerce business problems using data-driven insights.

## Project Structure
- `notebooks/`: Jupyter notebooks containing data cleaning, transformation, and exploratory data analysis (EDA).
- `messy datasets/`: Raw, unprocessed data used as the starting point for the analysis.
- `guide.md`: A step-by-step E-Commerce Data Analytics Project Guide outlining the analytical process.
- `PROJECT_STRATEGY_GUIDELINES.md`: Strategic guidelines detailing the project's overall direction.

## Methodology
The project follows a 9-step structured approach:
1. **Business Problem**: Defining core objectives, key questions, and KPIs.
2. **Data Collection**: Sourcing necessary raw data (Customers, Orders, Products, etc.).
3. **Data Understanding**: Familiarizing with dataset structures, dimensions, and types.
4. **Data Cleaning**: Handling missing values, duplicates, and standardizing formats.
5. **Data Transformation**: Feature engineering, joining tables, and aggregations.
6. **Exploratory Data Analysis (EDA)**: Investigating patterns, anomalies, and relationships visually.
7. **Analysis / Dashboarding**: Deep-dive quantitative analytics and interactive visuals (e.g., SQL, Power BI).
8. **Insights**: Synthesizing numerical findings into clear business truths.
9. **Recommendations**: Proposing actionable strategies based on insights to drive business decisions.

## Getting Started
To explore the project, start by reviewing `guide.md` to understand the methodology, then dive into the `notebooks/` directory to see the data processing and analysis in action.
